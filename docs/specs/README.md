# Especificaciones - msedi-catalogos

## Alcance

Microservicio de consulta consumido solamente por Angular. No tiene una HU propia dentro de HU001-HU012 y no es consumido por otros microservicios.

## Endpoint

`GET /api/v1/catalogos/{claveCatalogo}`
